### Автотесты API Stellar Burgers 🚀

Автоматизированные тесты для REST API космической бургерной на Python (pytest + requests). 

### ## Структура проекта

* tests/test_create_user.py — создание пользователя
* tests/test_login_user.py — авторизация пользователя
* tests/test_change_user.py — изменение данных пользователя
* tests/test_orders.py — создание и получение заказов
* conftest.py — фикстуры для генерации данных и очистки базы после тестов (teardown)
* urls.py — эндпоинты приложения

### ## Итоги работы

* **Изоляция и чистота данных:** В conftest.py реализовал фикстуры для динамического создания уникальных тестовых данных и их автоматического удаления (teardown) после каждого прогона, что предотвращает загрязнение базы данных.
* **Масштабируемость архитектуры:** Вынесла всю маршрутизацию и эндпоинты в отдельный файл конфигурации urls.py, исключив дублирование кода и упростив поддержку тестов.
* **Анализ результатов:** Интегрировала фреймворк Allure для генерации подробных интерактивных отчетов с логами запросов и ответов.

### ## Запуск тестов

python -m pytest -v tests/

### ## Просмотр отчёта Allure

python -m pytest -v tests/ --alluredir=allure-results
allure serve allure-results
